# arduino-game
a simple console using an arduino nano , buttons and an lcd screen !!
this is a simple game console using an arduino nano , 128x64 oled display and a couple of buttons, currently it has 2 games whihc are like flappy bird and crossy road but more features coming soon like a pause menu a home menu , difficulty and also sound using a simple piezo buzzer , high scores and even some basic animations 
enjoy! :)
